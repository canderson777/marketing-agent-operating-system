| Token | Value | Use |
|-------|-------|-----|
| Background (base) | `#0B0E14` | page background (near-black navy) |
| Panel / card | `#11151E` (rgba(17,21,30,.85)) | cards, sidebars |
| Panel alt | `#1E2938` (rgb 30,41,59) | secondary surfaces |
| Border / muted | `#334155` / `#475569` | hairlines, dividers |
| Text primary | `#FFFFFF` | headings, body |
| Text muted | `#CBD5E1` | secondary text |
| Text faint | `#94A3B8` / `#64748B` | labels, placeholders |
| **Accent / CTA** | **`#FFB703`** | primary buttons, links, highlights |

**Buttons:** gold background `#FFB703`, **black** text `#000000`, border-radius `6px`.
**Secondary buttons:** white bg `#FFFFFF`, black text, radius `6px`.

## Typography

- **Headings:** `Montserrat, sans-serif`
- **Body / UI:** `"Open Sans", sans-serif`

## Voice

Calm, direct, specific, low-pressure. See `brand-voice.md`. No urgency theater, no agency jargon, no hype adjectives. Frame problems as missed opportunity, never failure.
