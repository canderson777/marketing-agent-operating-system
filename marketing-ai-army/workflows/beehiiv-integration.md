# beehiiv Integration

Status: stub.

Use this when the job includes newsletter publishing, list operations, or publication reporting.

## When it matters
- publish a newsletter issue
- manage audience segments
- review newsletter performance
- connect content production to actual send operations

## Minimum operating rule
If beehiiv access is not available, still draft the newsletter package in markdown and mark publishing as a manual step.

## Inputs to prepare
- newsletter goal
- audience segment
- subject line options
- body draft
- CTA
- send date

## Output
- newsletter send package
- segment recommendation
- KPI plan
- manual fallback steps
