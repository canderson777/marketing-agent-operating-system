# Offer Library

Use this file to define, compare, and improve offers.

## Offer Fields

| Field | Notes |
|---|---|
| Offer name | What the audience sees. |
| Type | Product, service, course, subscription, community, event, affiliate, sponsorship, lead magnet. |
| Audience | Who it is for. |
| Problem solved | The specific problem. |
| Outcome | What changes after using it. |
| Price | Exact price or range. |
| CTA | The action to take. |
| Proof | Testimonials, case studies, examples, metrics, authority. |
| Objections | Reasons people hesitate. |
| Guarantee or risk reducer | Only if approved and true. |

## Offer Strength Checklist

- Clear audience.
- Clear pain.
- Clear outcome.
- Clear CTA.
- Proof or credibility.
- Reason to act now.
- Low-friction next step.
- Fits the channel being used.

## Common Offer Types

- Free consultation.
- Lead magnet.
- Newsletter signup.
- Product trial.
- Demo.
- Webinar.
- Audit.
- Discount.
- Bundle.
- Paid community.
- Sponsorship package.
- Affiliate/referral reward.

## Offer Improvement Prompts

When an offer is weak, improve:

- Specificity.
- Proof.
- Risk reduction.
- Urgency.
- Audience fit.
- CTA simplicity.
- Positioning.
