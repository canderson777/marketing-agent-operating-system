# Metrics Dashboard

Every strategy needs measurement. Use the metrics that match the goal and funnel stage.

## Funnel Metrics

| Funnel Stage | Primary Metrics |
|---|---|
| Awareness | Reach, impressions, views, audience growth, branded search |
| Engagement | Comments, shares, saves, replies, watch time, click-through rate |
| Consideration | Landing page visits, guide downloads, demo views, email signups |
| Conversion | Sales, booked calls, trials, checkout rate, cost per acquisition |
| Retention | Repeat purchases, churn, active users, renewal rate |
| Referral | Referrals, affiliate sales, invite rate, partner leads |

## Channel Metrics

| Channel | Metrics |
|---|---|
| Email | List growth, open rate, click rate, reply rate, conversion rate, unsubscribe rate |
| Social | Reach, engagement rate, saves, shares, profile clicks, follower growth |
| SEO/AEO | Organic traffic, rankings, impressions, clicks, featured snippets, AI-answer citations |
| Paid Ads | Spend, CTR, CPC, CPA, ROAS, conversion rate, frequency |
| Content | Views, time on page, leads, assisted conversions, shares |
| Outreach | Sends, replies, positive replies, booked calls, close rate |
| Partnerships | Partner leads, co-marketing reach, referrals, revenue |
| Events | Registrations, attendance, show rate, questions, follow-up conversions |

|  |  |  |  |

## What Did Not Work
- [Insight]

## Optimization Rules

- Do not scale unclear winners.
- Do not judge organic content from one post.
- Look for repeatable patterns.
- Separate creative performance from channel performance.
- Track one primary metric per campaign.
- Keep a simple decision rule before launch.
