# Request Template

Use this when you want one clean intake block for the Marketing Agent Operating System.

Paste this into chat, fill it in fast, and let the master agent route the work.

```md
/marketing-system

PROJECT: [Brand, business, person, or offer]
GOAL: [What needs to happen]
AUDIENCE: [Who this is for]
OFFER: [What is being promoted]
CTA: [Exact next step]
CHANNELS: [X, LinkedIn, email, blog, YouTube, local SEO, etc.]
ASSETS: [Docs, journal entries, screenshots, links, transcripts, notes]
CONSTRAINTS: [Tone, budget, deadlines, platform limits, banned angles]
TOOLS: [Preferred tools, banned tools, or markdown-only]
DATA SENSITIVITY: [Normal or sensitive]
OUTPUT: [What deliverable you want back]
```

## Fast Rules
- Fill in what you know.
- Leave blanks when speed matters.
- The master agent should make labeled assumptions instead of stalling.
- Use brand files under `../brands/` when they already answer a field.
- For a personal brand, use its journal/notes doc as the first source of raw content.
